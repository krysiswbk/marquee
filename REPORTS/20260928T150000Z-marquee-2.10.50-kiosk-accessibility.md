## FINDINGS

The discrepancy was confirmed in source and rendered behavior. `kiosk-menu.js`
created the selected destination as a sibling overlay but left the dashboard
siblings in the accessibility tree and potentially focusable. The fix gives the
overlay an explicit lifecycle: the pre-existing dashboard siblings are stored,
set `inert` and `aria-hidden="true"` for active destinations, and restored from
their original values on Home or interruption. Destination navigation uses
history entries so browser back returns to Home; Escape and Home restore the
Home rail link focus.
