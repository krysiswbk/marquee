# Marquee 2.10.1 — Kiosk destination shell

Pass 1 reconciles the completed 2.10.0 modernization into a reproducible Git
revision and replaces the Live/Kiosk generic Menu entry point with a shared
destination rail.

Wide layouts expose Home and enabled provider destinations directly. Narrow
layouts preserve priority destinations and move only the destinations that do
not fit into an explicit More destinations dialog. Controls retain keyboard and
touch access, active state, safe-area spacing, and actionable offline/empty/
stale/provider-health messaging.
