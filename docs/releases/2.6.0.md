# Marquee 2.6.0 release — 2026-09-10

Host: PVE1 / CT 127, `/opt/marquee`, http://10.10.9.37:8084.

Added live/kiosk previous, next, and Freeze/Resume controls with keyboard
shortcuts. Freeze retains fresh data and releases expired content. Removed
repeated weather summary text, including duplicated rows from cached feeds.
Runtime version now reads VERSION. Container CI is configured to run tests
before image publication (workflow prepared locally; not pushed to GitHub).

Validation: 125 pytest tests and 14 subtests passed; application self-test
passed. Chromium fixtures passed at 1280x800 and 390x844 for navigation,
freeze/resume, keyboard, weather deduplication, button bounds and Cast isolation.
Deployed health endpoint reports 2.6.0. Live Chromium verified freeze/resume,
returned to automatic selection, and reported zero JavaScript errors. One
eligible weather screen was available at validation time; multi-screen
navigation was verified with fixtures.

Deployment used the host's docker-compose executable. Initial attempts found
the older Compose CLI and a hardcoded runtime version; the guarded deployment
restored the baseline before the corrected release. Final image: 353d950e6ff3.

Rollback: source archive `/opt/marquee-backups/pre-2.6.0-20260910/source.tar.gz`
and image `marquee:rollback-2.6.0-20260910` are retained inside CT 127. Restore
source archive into /opt/marquee, tag the rollback image as marquee:local, and
run `docker-compose -f docker-compose.yml up -d --no-build` there. Config/data
volume was not changed by this release. Existing open displays need a reload
to acquire the new JavaScript.
